# Thermicien 2.0

Outil web pour thermicien, fonctionnant entièrement dans le navigateur : aucune installation, aucun serveur.

## Contenu du fichier

Le fichier `Thermicien_2_0.html` est autonome. Il regroupe dans une seule page :

- l'interface d'accueil avec des cartes d'accès aux outils ;
- des schémas animés affichés à l'ouverture de chaque outil ;
- les outils eux-mêmes, intégrés dans le fichier sous forme de bloc de données (variable `TOOLS`) ;
- le style visuel (thème clair par défaut, thème sombre automatique selon les préférences du système).
